Cómo jugar

La bola no se conduce directamente. Dibuja objetos físicos para que ruede, caiga, sea golpeada o transportada hasta todas las estrellas.

〰 Trazo
Rampas, puentes, barreras y palancas.
⬡ Forma
Cierra el dibujo para crear un peso sólido.
◉ Rueda
Dibuja un círculo. Puede rodar y empujar.
⊙ Pivote
Toca un punto y dibuja después una pieza cercana.
⌁ Cuerda
Toca dos cuerpos o puntos para unirlos.
⌫ Borrador
Elimina tus construcciones y recupera tinta.

Gestos

Toca la bola a un lado para darle un impulso pequeño. Toca un cohete para encenderlo. Mantén pulsado un objeto dibujado para borrarlo.

Medallas

La primera se obtiene resolviendo el nivel; la segunda, usando poca tinta; la tercera, combinando mecanismos como ruedas, cuerdas o pivotes.
