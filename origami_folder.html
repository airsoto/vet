A dark interface for loading, filtering and visualizing .fold files. The search box finds figures by filename, and the right-hand panel tries to show a reference image for the selected figure.

Based on Flat-Folder. Flat-Folder is software written by Jason S. Ku to compute and analyze valid flat-foldable states of flat-foldable crease patterns, both assigned and unassigned. Original repository.
