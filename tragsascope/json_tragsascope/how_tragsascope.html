Qué hace la web y cómo está construida

TragsaScope organiza contratos públicos de TRAGSA y TRAGSATEC, relaciona cada adjudicatario con las personas documentadas en sus sociedades y busca coincidencias con otras empresas y con personas vinculadas oficialmente al Grupo TRAGSA. Todo se presenta como pistas documentales para revisar, no como conclusiones automáticas.

Funcionamiento principal

Contratos → empresas → personas → coincidencias → fuentes

La web carga archivos JSON, crea índices en el navegador y permite recorrer cada relación hasta su contrato, empresa, persona, cargo, fecha y fuente documental.

1. ¿Qué hace TragsaScope?

En términos sencillos, la web responde cuatro preguntas.

1

¿A quién contratan?

Usa el campo linked_people de cada organización, obtenido principalmente de información societaria y otras fuentes documentales.

Normaliza nombres y detecta cuándo el mismo nombre aparece relacionado con dos o más empresas adjudicatarias.

4

¿También aparece en TRAGSA/TRAGSATEC?

Compara las personas de las adjudicatarias con una lista separada de personas documentadas oficialmente en el Grupo TRAGSA.

3. ¿Cómo está hecha?

No necesita una base de datos en el servidor. La mayor parte del trabajo se prepara antes y la web hace los cruces finales en el navegador.

Preparación

Python

Los scripts recopilan, limpian, deduplican y transforman la información en archivos JSON manejables.

Datos

JSON fragmentados

Los contratos y relaciones grandes se dividen en varios archivos para no obligar al navegador a descargar todo al abrir la página.

Interfaz

HTML + CSS + JavaScript

El index.html carga solo lo necesario, crea índices locales y muestra tablas, fichas, filtros, gráficas y cruces.

Privacidad de publicación: en esta página no se muestran rutas absolutas del ordenador usado para generar los datos. Los ejemplos utilizan nombres de archivo y rutas relativas como ./json_tragsascope/....

Compara los nombres de adjudicatarias con la lista oficial ampliada de TRAGSA/TRAGSATEC.

class RateLimiter:
    def __init__(self, delay: float, jitter: float = 0.35):
        self.delay = max(0.0, delay)
        self.jitter = max(0.0, jitter)
        self.last = 0.0

    def wait(self) -> None:
        elapsed = time.monotonic() - self.last
        target = self.delay + random.uniform(0, self.jitter)
        if elapsed < target:
            time.sleep(target - elapsed)
        self.last = time.monotonic()


def norm_text(value: Any) -> str:
    s = str(value or "")
    s = unicodedata.normalize("NFKD", s)
    s = "".join(ch for ch in s if not unicodedata.combining(ch))
    s = s.upper()
    s = re.sub(r"[^A-Z0-9]+", " ", s)
    return re.sub(r"\s+", " ", s).strip()


def compact_company_name(name: str) -> str:
    s = re.sub(r"\([^)]{0,140}\)", " ", name or "")
    s = re.sub(r"\b(?:S\.?L\.?U?\.?|S\.?A\.?U?\.?|SLP|SCOOP|S\.COOP\.?)\b", " ", s, flags=re.I)
    s = re.sub(r"\s+", " ", s).strip(" ,.;-")
    return s


def load_json(path: Path) -> Any:
    with path.open("r", encoding="utf-8") as f:
        return json.load(f)


def unwrap_items(data: Any) -> List[Dict[str, Any]]:
    if isinstance(data, list):
        return [x for x in data if isinstance(x, dict)]
    if isinstance(data, dict) and isinstance(data.get("items"), list):
        return [x for x in data["items"] if isinstance(x, dict)]
    return []


def atomic_dump_json(path: Path, data: Any) -> None:
    tmp = path.with_suffix(path.suffix + ".tmp")
    with tmp.open("w", encoding="utf-8") as f:
        json.dump(data, f, ensure_ascii=False, separators=(",", ":"))
    os.replace(tmp, path)


def cache_key(prefix: str, text: str) -> str:
    h = hashlib.sha256(text.encode("utf-8", errors="ignore")).hexdigest()[:24]
    return f"{prefix}_{h}.json"


def canonical_person_name(raw: str) -> Optional[str]:
    """Filtra candidatos obvios que no parecen personas.

    No intenta reordenar apellidos/nombre: conserva la forma publicada.
    """
    if not raw:
        return None
    s = html.unescape(raw)
    s = re.sub(r"\s+", " ", s).strip(" \t\n\r,;:.()-")
    s = re.sub(r"\s+\b(?:DNI|NIF)\b\s*[:\-]?\s*[A-Z0-9-]+$", "", s, flags=re.I).strip()
    if len(s) < 5 or len(s) > 120:
        return None
    if re.search(r"\d{2,}", s):
        return None
    if NOISE_RE.search(s):
        return None
    if LEGAL_ENTITY_RE.search(s):
        return None
    # Evita frases completas o textos de navegación.
    words = re.findall(r"[A-Za-zÁÉÍÓÚÜÑáéíóúüñÀ-ÿ'’-]+", s)
    if not (2 <= len(words) <= 8):
        return None
    if any(len(w) > 28 for w in words):
        return None
    stop = {"DE", "DEL", "LA", "LAS", "LOS", "Y", "DA", "DO", "DOS", "DAS", "VAN", "VON"}
    informative = [w for w in words if norm_text(w) not in stop]
    if len(informative) < 2:
        return None
    # Si está todo en minúscula y parece una frase, rechazo conservador.
    alpha = "".join(words)
    if alpha.islower():
        return None
    return s


def split_people_block(block: str) -> List[str]:
    block = block.strip()
    m = NEXT_ROLE_RE.search(block)
    if m:
        block = block[:m.start()]
    # Cortes adicionales frecuentes en snippets.
    block = re.split(r"\s+Datos registrales\b|\s+Otros conceptos\b|\s+Modificaciones estatutarias\b", block, maxsplit=1, flags=re.I)[0]
    pieces = re.split(r"\s*;\s*|\s+\|\s+|\s+·\s+", block)
    out: List[str] = []
    for piece in pieces:
        # Si el buscador pega dos cargos separados por punto, quedarse con el primero.
        piece = re.split(r"\.\s+(?=[A-ZÁÉÍÓÚÜÑ][A-Za-zÁÉÍÓÚÜÑáéíóúüñ])", piece, maxsplit=1)[0]
        p = canonical_person_name(piece)
        if p:
            out.append(p)
    return out


def extract_people_from_text(text: str, source_url: str, org: Dict[str, Any], source_kind: str, query: str = "") -> List[Evidence]:
    if not text:
        return []
    text = BeautifulSoup(text, "html.parser").get_text(" ") if "<" in text and ">" in text else text
    text = re.sub(r"\s+", " ", html.unescape(text))
    found: List[Evidence] = []
    for m in ROLE_PREFIX_RE.finditer(text):
        role = re.sub(r"\s+", " ", m.group("role")).strip()
        names_block = m.group("names")
        # Limita el bloque en caso de snippets largos sin puntuación limpia.
        names_block = names_block[:350]
        for name in split_people_block(names_block):
            conf = 98 if "boe.es" in urlparse(source_url).netloc.lower() else 80
            found.append(Evidence(
                organization_id=str(org.get("id", "")),
                organization_name=str(org.get("name") or org.get("legal_name") or ""),
                person=name,
                role=role,
                source_url=source_url,
                source_kind=source_kind,
                query=query,
                confidence=conf,
            ))
    return found


def is_natural_person_org(org: Dict[str, Any]) -> bool:
    nif = str(org.get("nif") or "").upper().strip()
    return bool(DNI_RE.match(nif) or NIE_RE.match(nif))


def build_local_evidence(
    organizations: List[Dict[str, Any]],
    people_files: Sequence[Path],
    relationship_files: Sequence[Path],
    role_interval_files: Sequence[Path],
    event_files: Sequence[Path],
) -> Tuple[Dict[str, Set[str]], List[Evidence]]:
    """Aprovecha los JSON ya existentes, sin tocar el fichero final salvo linked_people."""
    org_by_id = {str(o.get("id")): o for o in organizations if o.get("id")}
    people_by_id: Dict[str, str] = {}
    for pth in people_files:
        for p in unwrap_items(load_json(pth)):
            pid = str(p.get("id") or "")
            name = canonical_person_name(str(p.get("name") or ""))
            if pid and name:
                people_by_id[pid] = name

    names_by_org: Dict[str, Set[str]] = defaultdict(set)
    evidence: List[Evidence] = []

    # Relaciones: person -> org. Incluye SOCIAL_ROLE_EVENT, socio único y snapshots oficiales.
    for pth in relationship_files:
        for r in unwrap_items(load_json(pth)):
            source = str(r.get("source") or "")
            target = str(r.get("target") or "")
            holder_type = str(r.get("holder_type") or "")
            if target not in org_by_id:
                continue
            if not source.startswith("person:") and holder_type != "person":
                continue
            name = people_by_id.get(source)
            if not name:
                name = canonical_person_name(str(r.get("raw_holder") or ""))
            if not name:
                continue
            # raw_holder puede contener varias personas juntas. Solo lo usamos si es una persona limpia.
            names_by_org[target].add(name)
            evidence.append(Evidence(
                organization_id=target,
                organization_name=str(org_by_id[target].get("name") or ""),
                person=name,
                role=str(r.get("role") or r.get("type") or "relación documentada"),
                source_url=str(r.get("evidence_url") or ""),
                source_kind="local_relationship",
                confidence=100 if r.get("evidence_url") else 90,
            ))

    # Intervalos de cargos.
    for pth in role_interval_files:
        for it in unwrap_items(load_json(pth)):
            oid = str(it.get("organization_id") or "")
            pid = str(it.get("person_id") or "")
            if oid not in org_by_id:
                continue
            name = people_by_id.get(pid)
            if not name:
                continue
            names_by_org[oid].add(name)
            evidence.append(Evidence(
                organization_id=oid,
                organization_name=str(org_by_id[oid].get("name") or ""),
                person=name,
                role=str(it.get("role") or "cargo BORME"),
                source_url=str(it.get("start_evidence_url") or it.get("end_evidence_url") or ""),
                source_kind="local_role_interval",
                confidence=100 if (it.get("start_evidence_url") or it.get("end_evidence_url")) else 90,
            ))

    # Eventos societarios: extrae por patrón del raw_text. Útil cuando el parser de people fue imperfecto.
    for pth in event_files:
        for ev in unwrap_items(load_json(pth)):
            oid = str(ev.get("organization_id") or "")
            if oid not in org_by_id:
                continue
            url = str(ev.get("source_url") or "")
            for e in extract_people_from_text(str(ev.get("raw_text") or ""), url, org_by_id[oid], "local_borme_event"):
                names_by_org[oid].add(e.person)
                evidence.append(e)

    return names_by_org, evidence


class WebEnricher:
    def __init__(self, cache_dir: Path, delay: float, max_results: int, timeout: float, user_agent: str, search_depth: str = 'normal'):
        self.cache_dir = cache_dir
        self.cache_dir.mkdir(parents=True, exist_ok=True)
        self.search_cache = cache_dir / "search"
        self.page_cache = cache_dir / "pages"
        self.search_cache.mkdir(exist_ok=True)
        self.page_cache.mkdir(exist_ok=True)
        self.max_results = max(1, max_results)
        self.search_depth = search_depth
        self.timeout = timeout
        self.rate = RateLimiter(delay)
        self.session = requests.Session()
        self.session.headers.update({
            "User-Agent": user_agent,
            "Accept-Language": "es-ES,es;q=0.9,en;q=0.6",
        })

    def queries_for_org(self, org: Dict[str, Any]) -> List[str]:
        name = str(org.get("legal_name") or org.get("name") or "").strip()
        nif = str(org.get("nif") or "").strip()
        compact = compact_company_name(name)
        queries: List[str] = []
        # Orden: primero señales fuertes y fuentes oficiales.
        if nif:
            queries.append(f'"{nif}" administrador consejero apoderado')
        if name:
            queries.append(f'site:boe.es/diario_borme "{name}"')
        if self.search_depth in {"normal", "deep"} and name:
            queries.append(f'"{name}" administrador consejero apoderado presidente director gerente')
        if self.search_depth == "deep":
            if nif:
                queries.append(f'"{nif}" presidente director gerente socio unico titular real')
            if name:
                queries.append(f'"{name}" CEO gerente propietario accionista')
            if compact and compact != name and len(compact) >= 6:
                queries.append(f'site:boe.es/diario_borme "{compact}"')
        # Deduplicación conservando orden.
        return list(dict.fromkeys(queries))

    def search(self, query: str) -> List[Dict[str, str]]:
        path = self.search_cache / cache_key("search", query)
        if path.exists():
            try:
                return list(load_json(path))
            except Exception:
                pass
        self.rate.wait()
        try:
            global DDGS
            if DDGS is None:
                try:
                    from ddgs import DDGS as _DDGS
                except ImportError as exc:
                    raise RuntimeError("Falta ddgs. Ejecuta: pip install -U ddgs") from exc
                DDGS = _DDGS
            raw = DDGS().text(query, region="es-es", safesearch="moderate", max_results=self.max_results)
            results = []
            for r in raw or []:
                if not isinstance(r, dict):
                    continue
                results.append({
                    "title": str(r.get("title") or ""),
                    "body": str(r.get("body") or r.get("snippet") or ""),
                    "href": str(r.get("href") or r.get("url") or ""),
                })
            atomic_dump_json(path, results)
            return results
        except Exception as e:
            logging.warning("Búsqueda fallida %r: %s", query, e)
            return []

    def fetch_page(self, url: str) -> str:
        if not url.startswith(("http://", "https://")):
            return ""
        path = self.page_cache / cache_key("page", url)
        if path.exists():
            try:
                data = load_json(path)
                return str(data.get("text") or "")
            except Exception:
                pass
        self.rate.wait()
        try:
            r = self.session.get(url, timeout=self.timeout, allow_redirects=True)
            ctype = r.headers.get("content-type", "").lower()
            if r.status_code != 200 or not any(x in ctype for x in ("text/html", "application/xhtml", "text/plain")):
                return ""
            if len(r.content) > 4_000_000:
                return ""
            soup = BeautifulSoup(r.text, "html.parser")
            for tag in soup(["script", "style", "noscript", "svg"]):
                tag.decompose()
            text = re.sub(r"\s+", " ", soup.get_text(" ", strip=True))
            atomic_dump_json(path, {"url": url, "text": text[:1_500_000]})
            return text
        except Exception as e:
            logging.debug("No se pudo descargar %s: %s", url, e)
            return ""

    def result_relevant(self, org: Dict[str, Any], result: Dict[str, str]) -> bool:
        hay = norm_text(" ".join([result.get("title", ""), result.get("body", ""), result.get("href", "")]))
        nif = norm_text(org.get("nif"))
        name = norm_text(compact_company_name(str(org.get("legal_name") or org.get("name") or "")))
        # NIF es la señal más fuerte.
        if nif and nif in hay:
            return True
        tokens = [t for t in name.split() if len(t) >= 4 and t not in {"SOCIEDAD", "LIMITADA", "ANONIMA", "UNIPERSONAL"}]
        if not tokens:
            return False
        # Exige al menos 2 tokens del nombre o el 60% si es corto.
        hits = sum(t in hay for t in tokens[:8])
        need = 1 if len(tokens) == 1 else max(2, round(min(len(tokens), 6) * 0.6))
        return hits >= need

    def enrich_org(self, org: Dict[str, Any]) -> Tuple[Set[str], List[Evidence]]:
        names: Set[str] = set()
        evidences: List[Evidence] = []
        seen_urls: Set[str] = set()

        for query in self.queries_for_org(org):
            for result in self.search(query):
                url = result.get("href", "")
                snippet = " ".join([result.get("title", ""), result.get("body", "")])
                if not self.result_relevant(org, result):
                    continue

                # 1) Extraer del propio resultado del buscador.
                for e in extract_people_from_text(snippet, url, org, "search_snippet", query):
                    names.add(e.person)
                    evidences.append(e)

                # 2) Descargar páginas prioritarias o que contienen palabras de cargo.
                host = urlparse(url).netloc.lower()
                roleish = any(w in norm_text(snippet) for w in [norm_text(x) for x in ROLE_WORDS])
                priority = host.endswith("boe.es") or roleish
                if not url or url in seen_urls or not priority:
                    continue
                seen_urls.add(url)
                page = self.fetch_page(url)
                if not page:
                    continue
                # Comprobación de identidad de empresa antes de extraer nombres de una página completa.
                page_norm = norm_text(page[:250_000])
                nif = norm_text(org.get("nif"))
                cname = norm_text(compact_company_name(str(org.get("legal_name") or org.get("name") or "")))
                company_ok = bool(nif and nif in page_norm)
                if not company_ok and cname:
                    toks = [t for t in cname.split() if len(t) >= 4][:6]
                    company_ok = sum(t in page_norm for t in toks) >= max(1, min(2, len(toks)))
                if not company_ok:
                    continue
                for e in extract_people_from_text(page, url, org, "boe_borme" if host.endswith("boe.es") else "web_page", query):
                    names.add(e.person)
                    evidences.append(e)

        return names, evidences


def evidence_key(e: Evidence) -> Tuple[str, str, str, str]:
    return (e.organization_id, norm_text(e.person), e.role, e.source_url)


def write_evidence_jsonl(path: Path, evidence: Iterable[Evidence]) -> None:
    seen: Set[Tuple[str, str, str, str]] = set()
    with path.open("w", encoding="utf-8") as f:
        for e in evidence:
            k = evidence_key(e)
            if k in seen:
                continue
            seen.add(k)
            f.write(json.dumps(asdict(e), ensure_ascii=False) + "\n")


def merge_person_names(existing: Iterable[str], new: Iterable[str]) -> List[str]:
    # Deduplicación por nombre normalizado, conservando la primera grafía.
    out: Dict[str, str] = {}
    for name in list(existing) + list(new):
        p = canonical_person_name(str(name))
        if p:
            out.setdefault(norm_text(p), p)
    return sorted(out.values(), key=lambda x: norm_text(x))


def validate_unchanged(original: List[Dict[str, Any]], enriched: List[Dict[str, Any]]) -> None:
    if len(original) != len(enriched):
        raise RuntimeError("Ha cambiado el número de organizaciones")
    for i, (a, b) in enumerate(zip(original, enriched)):
        aa = copy.deepcopy(a)
        bb = copy.deepcopy(b)
        bb.pop("linked_people", None)
        aa.pop("linked_people", None)
        if aa != bb:
            raise RuntimeError(f"Se ha modificado un campo original en el registro {i} ({a.get('id')})")

def main() -> int:

    logging.basicConfig(
        level=logging.DEBUG if args.verbose >= 2 else logging.INFO if args.verbose else logging.WARNING,
        format="%(asctime)s %(levelname)s %(message)s",
    )

    source_data = load_json(args.input)
    source_items = unwrap_items(source_data)
    if not source_items:
        raise SystemExit("No se encontraron organizaciones en el JSON de entrada")

    # Copia profunda para garantizar que no se cambie nada salvo linked_people.
    enriched_data = copy.deepcopy(source_data)
    enriched_items = unwrap_items(enriched_data)

    # Reanudar desde un output previo, solo recuperando linked_people por id.
    resume_by_id: Dict[str, List[str]] = {}
    if args.resume and args.output.exists():
        try:
            for o in unwrap_items(load_json(args.output)):
                if o.get("id") and isinstance(o.get("linked_people"), list):
                    resume_by_id[str(o["id"])] = [str(x) for x in o["linked_people"]]
        except Exception as e:
            logging.warning("No se pudo reutilizar el output anterior: %s", e)

    for o in enriched_items:
        existing = o.get("linked_people") if isinstance(o.get("linked_people"), list) else []
        existing = list(existing) + resume_by_id.get(str(o.get("id") or ""), [])
        o["linked_people"] = merge_person_names(existing, [])

    local_names, all_evidence = build_local_evidence(
        enriched_items,
        args.people,
        args.relationships,
        args.role_intervals,
        args.societary_events,
    )
    for o in enriched_items:
        oid = str(o.get("id") or "")
        o["linked_people"] = merge_person_names(o.get("linked_people", []), local_names.get(oid, set()))
        if args.include_natural_person_self and is_natural_person_org(o):
            o["linked_people"] = merge_person_names(o["linked_people"], [str(o.get("name") or "")])

    # Escribe un primer checkpoint aunque no haya web.
    validate_unchanged(source_items, enriched_items)
    atomic_dump_json(args.output, enriched_data)
    write_evidence_jsonl(args.evidence, all_evidence)

    if not args.web:
        with_people = sum(bool(o.get("linked_people")) for o in enriched_items)
        print(f"OK: {len(enriched_items)} organizaciones; {with_people} con linked_people. Salida: {args.output}")
        print(f"Evidencia: {args.evidence}")
        return 0

    web = WebEnricher(
        cache_dir=args.cache_dir,
        delay=args.delay,
        max_results=args.max_results,
        timeout=args.timeout,
        user_agent="Mozilla/5.0 (compatible; TragsaScopeResearch/1.0; +public-data-research)",
        search_depth=args.search_depth,
    )

    candidates = []
    for idx, o in enumerate(enriched_items):
        if o.get("category") == "grupo_tragsa":
            continue
        # Persona física adjudicataria: una búsqueda societaria no tiene el mismo sentido.
        if is_natural_person_org(o):
            continue
        if args.only_empty and o.get("linked_people"):
            continue
        candidates.append((idx, o))
    if args.max_companies > 0:
        candidates = candidates[:args.max_companies]

    print(f"Web: se investigarán {len(candidates)} organizaciones. Ctrl+C es seguro: se guarda checkpoint.")
    processed = 0
    try:
        for idx, org in candidates:
            processed += 1
            name = str(org.get("name") or org.get("legal_name") or org.get("id") or "")
            print(f"[{processed}/{len(candidates)}] {name}")
            try:
                names, ev = web.enrich_org(org)
                if names:
                    org["linked_people"] = merge_person_names(org.get("linked_people", []), names)
                    print(f"  + {len(names)} nombres candidatos documentados")
                all_evidence.extend(ev)
            except Exception as e:
                logging.warning("Error investigando %s: %s", name, e)

            if processed % max(1, args.checkpoint_every) == 0:
                validate_unchanged(source_items, enriched_items)
                atomic_dump_json(args.output, enriched_data)
                write_evidence_jsonl(args.evidence, all_evidence)
                print("  checkpoint guardado")
    except KeyboardInterrupt:
        print("\nInterrumpido por el usuario. Guardando progreso…")
    finally:
        validate_unchanged(source_items, enriched_items)
        atomic_dump_json(args.output, enriched_data)
        write_evidence_jsonl(args.evidence, all_evidence)

    with_people = sum(bool(o.get("linked_people")) for o in enriched_items)
    total_links = sum(len(o.get("linked_people") or []) for o in enriched_items)
    print(f"FIN: {len(enriched_items)} organizaciones; {with_people} con personas; {total_links} vínculos únicos.")
    print(f"JSON: {args.output}")
    print(f"Evidencia: {args.evidence}")
    print(f"Cache: {args.cache_dir}")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

def canon(s):
    s=str(s or '').strip()
    s=unicodedata.normalize('NFD', s)
    s=''.join(c for c in s if unicodedata.category(c)!='Mn')
    s=s.upper().replace('ª','A').replace('º','O')
    s=re.sub(r'[^A-Z0-9Ñ]+',' ',s)
    return re.sub(r'\s+',' ',s).strip()

def title_name(s):
    # Keep source capitalization if mixed; otherwise readable title case with common particles lowered.
    s=' '.join(str(s).split())
    if any(ch.islower() for ch in s): return s
    out=s.title()
    particles={'De','Del','La','Las','Los','Y','Da','Do'}
    words=[]
    for i,w in enumerate(out.split()):
        words.append(w.lower() if i and w in particles else w)
    return ' '.join(words)

7. Proceso de generación

El proceso práctico queda así:

1

Preparar la base

Partir de contratos, organizaciones, personas, relaciones y actos societarios extraídos y estructurados.

2

Enriquecer empresas

Ejecutar tragsa_enriquecer_empresas.py para añadir linked_people sin modificar los demás campos de las organizaciones.

3

Conservar evidencia

Guardar las evidencias detalladas en un JSONL independiente. El JSON de organizaciones queda más limpio.

4

Crear la lista TRAGSA

Ejecutar build_tragsa_people_extended.py para producir el conjunto separado de personas oficiales/documentadas.

5

Publicar JSON

Colocar los archivos JSON junto al sitio usando únicamente rutas relativas y nombres públicos.

6

Cargar la web

El index.html descarga primero los ficheros ligeros y carga contratos/relaciones pesadas solo cuando una función los necesita.

7

Calcular cruces

El navegador normaliza nombres, encuentra personas compartidas, cruza con TRAGSA/TRAGSATEC y, cuando procede, compara fechas.

8

Verificar

Cualquier coincidencia relevante debe revisarse en la fuente documental original antes de sacar conclusiones.

8. Qué significa —y qué no significa— una coincidencia

⚠️ Una coincidencia no demuestra un conflicto de interés

Un mismo nombre en una adjudicataria y en documentación de TRAGSA/TRAGSATEC puede ser una pista útil, pero por sí solo no demuestra que se trate de la misma persona, que el vínculo estuviera vigente en la fecha del contrato ni que exista incompatibilidad, trato de favor o irregularidad.

Coincidencia de nombre

Primer nivel. Sirve para localizar casos que merece la pena comprobar.

Coincidencia + cargo + fechas

Más informativa porque incorpora contexto societario y temporal, pero sigue requiriendo verificación.

Fuente original

Es el nivel decisivo: BORME, PLACSP, BOE o documento oficial enlazado.
