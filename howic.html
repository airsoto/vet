1. Descarga de datos desde Dialnet

Se utiliza Selenium y BeautifulSoup para automatizar la extracción de ejemplares desde la web de Dialnet. El script recorre IDs de ejemplares, accede a su página y extrae:

  • Año
  • Volumen
  • Título del artículo
  • Autores
  • Páginas

2. Generación de enlaces a los PDF en Archive.org

Una vez obtenido el JSON, se usa un script en Python para crear los enlaces de visualización directa del artículo desde Archive.org:

import json
meses = ["01-ene", "02-feb", ..., "12-dic"]
volumen_base = 160

with open("1.json", "r", encoding="utf-8") as f:
    articulos = json.load(f)

for articulo in articulos:
    volumen = int(articulo["volumen"])
    pagina_inicio = articulo["páginas"].split("-")[0].strip()
    mes = meses[(volumen - volumen_base) % 12]
    articulo["url"] = f"https://archive.org/details/iyc{año}/IYC{volumen}-{año}-{mes}/page/{pagina_inicio}/mode/2up"

with open("1_actualizado.json", "w", encoding="utf-8") as f:
    json.dump(articulos, f, indent=2, ensure_ascii=False)
