Buscador de PubMed y visor acoplado en Sci-Hub

Busca en PubMed aquí mismo, copia el DOI y ábrelo como PDF de acceso abierto.

Desarrollado por: Ángel Soto

🏠 volver a página de inicio

Se usa la API oficial de NCBI (esearch + esummary). Si no hay resultados, prueba con “cancer” o “dog heart”.

DOI / URL
*Se genera la URL de Sci-Hub con el DOI y se abre en otra pestaña. Úsalo bajo tu responsabilidad.
Consejos rápidos
  • En cada resultado: “Copiar DOI aquí” → baja el DOI directamente a la caja.
  • “Abrir PDF (OA)” usa Unpaywall (legal) para buscar versiones abiertas.
  • Si sale PMCID, puedes abrir el PDF de PMC directamente.
