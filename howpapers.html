¿Cómo está creado este buscador de artículos?

Este buscador ha sido creado mediante dos componentes principales:

1. Extracción de datos

Se usa un script en Python para recopilar artículos de revistas científicas veterinarias indexadas en PubMed, entre los años 1975 y 2025. Puedes consultar el programa aquí:

https://airsoto.github.io/vet/papers.py

El resultado es un archivo JSON con todos los artículos extraídos:

https://airsoto.github.io/vet/papers.json

2. Interfaz Web de Búsqueda

El siguiente código HTML es el motor del buscador, que permite filtrar artículos por título, autor o revista, y visualizar los resultados junto con los resúmenes:

<!DOCTYPE html> <html lang="es"> <head> <meta charset="UTF-8"> <title>Buscador de Artículos Veterinarios</title> <!-- Aquí empieza el CSS omitido para brevedad --> </head> <body> <h1 onclick="toggleModal()">Buscador de Artículos...</h1> <h2>Desarrollado por: Angel Soto</h2> <!-- Sección del modal con las revistas indexadas --> <!-- Sección de búsqueda con selectores e inputs --> <!-- Contenedor de resultados --> <script> let articles = []; async function cargarArticulos() { try { const response = await fetch('papers.json'); articles = await response.json(); } catch (error) { console.error(error); } } // Función de búsqueda... // Función de envío por correo... // Función para mostrar y ocultar el modal... cargarArticulos(); </script> </body> </html>

Nota: El código completo con estilos y scripts detallados puede visualizarse directamente en tu editor favorito o implementarse como base de un visor web en tu servidor.
