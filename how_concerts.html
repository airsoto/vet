Cómo funciona el scraper de la colección AJC

Esta página explica de forma clara y entretenida qué hace el script en Python, cómo se diseñó, cuál es su recorrido paso a paso y dónde encaja cada parte del código. También incluye una ventana para mostrar el script completo dentro del propio HTML.

¿Qué problema resuelve este script?

El objetivo del script es recorrer una colección de Internet Archive, localizar todos los enlaces cuyo identificador empieza por ajc, entrar en cada página de detalle del concierto y extraer información estructurada para guardarla en formato JSON.

En vez de copiar datos a mano de cientos de páginas, el script automatiza el trabajo y genera archivos fáciles de reutilizar después en una web, una base de datos o un buscador musical.
  • Concierto: título principal del evento.
  • Artista: texto anterior a la palabra Live.
  • Fecha de publicación: fecha del concierto/publicación.
  • Imagen del disco: enlace a una imagen descargable cuando exista.
  • Canciones: nombre, duración y enlace MP3 de cada pista.

El recorrido del programa

1
Busca todos los identificadores AJC
Primero consulta la colección y reúne los items cuyo identificador empieza por ajc.
2
Entra en cada página de detalle
Después abre cada URL del tipo https://archive.org/details/ajc....
3
Localiza los metadatos útiles
Lee el HTML buscando etiquetas como og:title, datePublished o bloques AudioObject.
4
Transforma los datos
Extrae el artista a partir del título, convierte duraciones ISO y limpia textos antes de guardarlos.
5
Genera JSON
Por último crea un JSON por concierto y, opcionalmente, un índice general con todos los conciertos.

Cómo se ha construido el Python

El script se planteó por bloques, para que cada parte tuviera una misión clara y fuera fácil de modificar. Esa separación hace que el código sea más entendible y más robusto.

  • Bloque de conexión: obtiene el HTML o el JSON desde la web.
  • Bloque de descubrimiento: encuentra todos los identificadores válidos ajc....
  • Bloque de parsing: analiza cada página y localiza título, fecha, canciones e imagen.
  • Bloque de transformación: adapta el texto bruto a campos útiles.
  • Bloque de guardado: crea los archivos JSON finales.

Ideas clave del diseño

  • Separar funciones pequeñas en lugar de meter todo en un único bloque gigante.
  • Usar nombres de función claros para que el script se lea casi como una explicación.
  • Incluir pausas pequeñas entre peticiones para no saturar el servidor.
  • Añadir fallbacks por si una página no trae todos los datos.
  • Guardar también los enlaces MP3 para poder reutilizarlos luego en un reproductor o catálogo.

Qué hace cada parte importante del scraper

A
Obtención de identificadores
La función que busca identificadores revisa la colección y reúne todos los items cuyo nombre empieza por ajc.
B
Extracción del concierto
Lee el meta property="og:title" y se queda con la parte útil del título, antes de los añadidos de Internet Archive.
C
Obtención del artista
A partir del título del concierto, recorta todo lo que aparece antes de la palabra Live.
D
Extracción de canciones
Busca bloques AudioObject, toma el nombre de la canción, su duración y el enlace asociado al MP3.
E
Generación de salida JSON
El resultado se guarda de forma estructurada, para que puedas reutilizarlo sin volver a raspar la web.
