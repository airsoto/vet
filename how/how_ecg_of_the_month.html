Objetivo del proyecto

El objetivo es convertir una colección dispersa de artículos de la sección ECG of the Month en una base de datos legible por máquinas. El resultado final es un JSON que puede alimentar una web docente, un buscador, un quiz clínico o una herramienta de revisión electrocardiográfica veterinaria.

🧠 Docencia ECG 📄 Artículos JAVMA 🖼️ Figuras ECG 🧬 JSON estructurado 🔗 Referencias con enlaces

Fuente de datos

Punto de entrada: la búsqueda de AVMA Journals con la consulta ECG of the Month. El script recorre desde la página 1 hasta la 36, usando URLs como:

https://avmajournals.avma.org/search?access=all&page=2&pageSize=10&q1=ECG+of+the+Month&sort=relevance

El script no intenta saltarse restricciones de acceso. Si la web requiere sesión institucional, permite usar cookies válidas del navegador mediante --cookies.

Flujo de extracción

1

Páginas de búsqueda

Recorre page=1 a page=36 y localiza enlaces de artículos.

2

Filtro ECG

Valida que el título o tipo editorial sea realmente ECG of the Month.

3

Extracción HTML

Lee autores, metadatos, cuerpo, figuras, discusión, notas y referencias.

4

Salida JSON

Guarda un archivo estructurado reutilizable para una web o base docente.

Selectores HTML principales

El scraper usa selectores estables de la página de AVMA. Los más importantes son:

meta[name="citation_*"]DOI, PDF original, revista, volumen, número, fecha y páginas.
.component-content-contributorsBloque de autores, credenciales, filiación y enlaces de búsqueda.
#articleBodyCuerpo principal del artículo. Aquí se separan caso, secciones, figuras y referencias.
#articleBody > pPrimeros párrafos antes del primer h2: descripción del caso clínico.
div.section h2Permite localizar secciones como ECG Interpretation y Discussion.
div.figureCada figura ECG, su URL, versión full-size, enlace de descarga y caption.
.footnoteGroup .footnoteNotas técnicas de equipos, monitores o aclaraciones de la publicación.
section.refSection .referenceReferencias con texto completo y enlaces Crossref, Google Scholar y Export Citation.

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
Scraper para AVMA Journals - ECG of the Month.

Recorre las paginas de busqueda:
  https://avmajournals.avma.org/search?access=all&page=N&pageSize=10&q1=ECG+of+the+Month&sort=relevance
extrae los enlaces de articulos, entra en cada articulo y crea un JSON con:
  autores, descripcion_del_caso, interpretacion_ecg, figuras, discusion, referencias, PDF, DOI, etc.

Instalacion:
  pip install requests beautifulsoup4 lxml

Uso basico:
  python avma_ecg_scraper.py --output ecg_of_the_month.json

Prueba con un HTML local de ejemplo:
  python avma_ecg_scraper.py --html-file "html ejemplo.html" --output ejemplo.json

Si AVMA bloquea el acceso por sesion/login institucional, exporta tu cookie del navegador y usa:
  python avma_ecg_scraper.py --cookies "cookie1=valor; cookie2=valor" --output ecg_of_the_month.json
"""

from __future__ import annotations

import argparse
import datetime as dt
import html as html_lib
import json
import re
import sys
import time
from dataclasses import dataclass
from pathlib import Path
from typing import Any, Optional
from urllib.parse import urljoin, urlsplit, urlunsplit

import requests
from bs4 import BeautifulSoup, NavigableString, Tag
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry

BASE_URL = "https://avmajournals.avma.org"
SEARCH_URL_TEMPLATE = (
    BASE_URL
    + "/search?access=all&page={page}&pageSize=10&q1=ECG+of+the+Month&sort=relevance"
)

DEFAULT_HEADERS = {
    "User-Agent": (
        "Mozilla/5.0 (X11; Linux x86_64) AppleWebKit/537.36 "
        "(KHTML, like Gecko) Chrome/143.0 Safari/537.36"
    ),
    "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8",
    "Accept-Language": "en-US,en;q=0.9,es;q=0.8",
    "Cache-Control": "no-cache",
    "Pragma": "no-cache",
    "Referer": BASE_URL + "/",
}


@dataclass
class FetchResult:
    url: str
    html: str
    status_code: int


def clean_text(text: Optional[str]) -> Optional[str]:
    """Normaliza texto sin destruir unidades ni simbolos."""
    if text is None:
        return None
    text = html_lib.unescape(text)
    text = text.replace("\xa0", " ")
    text = text.replace("\u2009", " ")
    text = text.replace("\u202f", " ")
    text = re.sub(r"[\r\t\f\v]+", " ", text)
    text = re.sub(r"\n\s*\n+", "\n\n", text)
    text = re.sub(r"[ ]+", " ", text)
    text = re.sub(r"\s+([,.;:?!])", r"\1", text)
    text = re.sub(r"([(\[])\s+", r"\1", text)
    text = re.sub(r"\s+([)\]])", r"\1", text)
    # No se eliminan espacios alrededor de guiones de forma global: evita convertir "50- or" en "50-or".
    text = text.strip()
    return text or None


def text_of(node: Optional[Tag], separator: str = "") -> Optional[str]:
    """Extrae texto de un nodo HTML evitando scripts, botones y bloques debug."""
    if node is None:
        return None
    # Clonar el nodo evita modificar el arbol original al eliminar subnodos.
    clone_soup = BeautifulSoup(str(node), "lxml")
    for bad in clone_soup.select(
        "script, style, button, .debug, .screen-reader-text, .visibility-hidden .screen-reader-text"
    ):
        bad.decompose()
    return clean_text(clone_soup.get_text(separator=separator, strip=False))


def normalize_for_match(text: Optional[str]) -> str:
    return re.sub(r"\s+", " ", (text or "").strip()).lower()


def absolute_url(href: Optional[str], base: str = BASE_URL) -> Optional[str]:
    if not href:
        return None
    href = href.strip()
    if not href:
        return None
    if href.startswith("//"):
        href = "https:" + href
    return urljoin(base, href)


def strip_query_and_fragment(url: str) -> str:
    parts = urlsplit(url)
    return urlunsplit((parts.scheme, parts.netloc, parts.path, "", ""))


def meta_content(soup: BeautifulSoup, name: Optional[str] = None, prop: Optional[str] = None) -> Optional[str]:
    attrs: dict[str, str] = {}
    if name:
        attrs["name"] = name
    if prop:
        attrs["property"] = prop
    tag = soup.find("meta", attrs=attrs)
    if tag and tag.get("content"):
        return clean_text(tag.get("content"))
    return None


def all_meta_contents(soup: BeautifulSoup, name: str) -> list[str]:
    values: list[str] = []
    for tag in soup.find_all("meta", attrs={"name": name}):
        value = clean_text(tag.get("content"))
        if value:
            values.append(value)
    return values


def make_session(cookie_header: Optional[str] = None) -> requests.Session:
    session = requests.Session()
    session.headers.update(DEFAULT_HEADERS)
    if cookie_header:
        session.headers["Cookie"] = cookie_header

    retry = Retry(
        total=4,
        connect=4,
        read=4,
        status=4,
        backoff_factor=1.0,
        status_forcelist=(429, 500, 502, 503, 504),
        allowed_methods=("GET", "HEAD"),
        raise_on_status=False,
    )
    adapter = HTTPAdapter(max_retries=retry, pool_connections=8, pool_maxsize=8)
    session.mount("https://", adapter)
    session.mount("http://", adapter)
    return session


def fetch(session: requests.Session, url: str, timeout: int = 30, delay: float = 0.5) -> FetchResult:
    time.sleep(max(0.0, delay))
    resp = session.get(url, timeout=timeout)
    if resp.status_code in (401, 403):
        raise RuntimeError(
            f"Acceso bloqueado ({resp.status_code}) para {url}. "
            "Prueba con --cookies si necesitas una sesion institucional/autenticada."
        )
    if resp.status_code >= 400:
        raise RuntimeError(f"HTTP {resp.status_code} al descargar {url}")
    resp.encoding = resp.encoding or "utf-8"
    return FetchResult(url=url, html=resp.text, status_code=resp.status_code)


def collect_article_links_from_search_html(html: str, page_url: str) -> list[str]:
    """Extrae posibles enlaces a articulos desde una pagina de resultados.

    El buscador puede repetir enlaces dentro de la tarjeta; se deduplican y luego
    cada articulo se valida por titulo/editorial type antes de extraerlo.
    """
    soup = BeautifulSoup(html, "lxml")
    candidates_all: list[str] = []
    candidates_ecg: list[str] = []

    for a in soup.select('a[href*="/view/journals/"]'):
        href = a.get("href")
        abs_url = absolute_url(href, page_url)
        if not abs_url:
            continue
        clean_url = strip_query_and_fragment(abs_url)
        path = urlsplit(clean_url).path
        if not path.endswith(".xml"):
            continue
        if any(skip in path for skip in (".issue-", "-overview.xml", "/pdfviewer/")):
            continue

        candidates_all.append(clean_url)

        a_text = text_of(a) or ""
        parent = a.find_parent(["article", "li", "div"])
        context = text_of(parent) if parent else a_text
        if "ecg of the month" in normalize_for_match(a_text) or "ecg of the month" in normalize_for_match(context):
            candidates_ecg.append(clean_url)

    chosen = candidates_ecg or candidates_all
    return dedupe_preserve_order(chosen)


def dedupe_preserve_order(items: list[str]) -> list[str]:
    seen: set[str] = set()
    out: list[str] = []
    for item in items:
        if item not in seen:
            seen.add(item)
            out.append(item)
    return out


def extract_definition_value(soup: BeautifulSoup, class_name: str) -> Optional[str]:
    dd = soup.select_one(f"dl.{class_name} dd")
    return text_of(dd) if dd else None


def extract_authors(soup: BeautifulSoup) -> list[dict[str, Any]]:
    authors: list[dict[str, Any]] = []

    for details in soup.select(".component-content-contributors .contributor-details"):
        if not isinstance(details, Tag):
            continue
        name_el = details.select_one('[data-testid="author-name"]')
        name = text_of(name_el)
        if not name:
            continue

        affiliation_el = details.select_one(".contributor-details-pop-up-affiliation .text")
        affiliation = text_of(affiliation_el)

        links: list[dict[str, Optional[str]]] = []
        popup = details.select_one(".contributor-details-pop-up-affiliation")
        if popup:
            for link in popup.select("a[href]"):
                links.append(
                    {
                        "label": text_of(link),
                        "url": absolute_url(link.get("href")),
                    }
                )

        # Credenciales: en esta web suelen aparecer como texto directo despues del bloque del autor.
        credential_parts: list[str] = []
        for child in details.contents:
            if isinstance(child, NavigableString):
                credential_parts.append(str(child))
            elif isinstance(child, Tag):
                classes = child.get("class", [])
                if "contributor-details-block" not in classes:
                    credential_parts.append(child.get_text(" ", strip=True))
        credentials = clean_text(" ".join(credential_parts))
        if credentials:
            credentials = re.sub(r"^(,|and)\s*", "", credentials).strip()
            credentials = credentials or None

        authors.append(
            {
                "name": name,
                "credentials": credentials,
                "affiliation": affiliation,
                "links": links,
            }
        )

    # Fallback si no esta visible el bloque de autores.
    if not authors:
        for name in all_meta_contents(soup, "citation_author"):
            authors.append({"name": name, "credentials": None, "affiliation": None, "links": []})

    return authors


def article_body(soup: BeautifulSoup) -> Optional[Tag]:
    return soup.select_one("#articleBody")


def extract_case_description(body: Optional[Tag]) -> Optional[str]:
    """Primeros parrafos del cuerpo antes de la primera seccion/h2."""
    if body is None:
        return None
    parts: list[str] = []
    for child in body.children:
        if isinstance(child, NavigableString):
            continue
        if not isinstance(child, Tag):
            continue
        if child.name in {"h1", "h2", "h3", "section"}:
            break
        if child.name == "div" and ("section" in child.get("class", []) or child.find(["h2", "h3"])):
            break
        if child.name == "p":
            t = text_of(child)
            if t:
                parts.append(t)
    return "\n\n".join(parts) if parts else None


def find_section(body: Optional[Tag], heading_contains: str) -> Optional[Tag]:
    if body is None:
        return None
    target = normalize_for_match(heading_contains)
    for h in body.find_all(["h2", "h3"]):
        h_text = normalize_for_match(text_of(h))
        if target in h_text:
            section = h.find_parent(
                lambda tag: isinstance(tag, Tag)
                and tag.name in {"div", "section"}
                and ("section" in tag.get("class", []) or tag.name == "section")
            )
            return section or h.parent
    return None


def extract_section_text(body: Optional[Tag], heading_contains: str, include_heading: bool = False) -> Optional[str]:
    section = find_section(body, heading_contains)
    if section is None:
        return None

    parts: list[str] = []
    heading = section.find(["h2", "h3"])
    if include_heading and heading:
        h_text = text_of(heading)
        if h_text:
            parts.append(h_text)

    # Parrafos directos: evita meter pies de figura que estan dentro de div.figure.
    direct_paragraphs = section.find_all("p", recursive=False)
    for p in direct_paragraphs:
        if "citation" in p.get("class", []):
            continue
        t = text_of(p)
        if t:
            parts.append(t)

    # Fallback para estructuras menos limpias.
    if len(parts) == (1 if include_heading else 0):
        for p in section.select(":scope > p"):
            t = text_of(p)
            if t:
                parts.append(t)

    return "\n\n".join(parts) if parts else None


def extract_figures(body: Optional[Tag], page_url: str) -> list[dict[str, Any]]:
    if body is None:
        return []
    figures: list[dict[str, Any]] = []

    for fig_div in body.select("div.figure"):
        fig_id = fig_div.get("id")
        label = text_of(fig_div.select_one("figcaption"))
        number = None
        number_source = " ".join(x for x in [fig_id or "", label or ""] if x)
        m = re.search(r"figure\s*(\d+)|fig(?:ure)?(\d+)", number_source, flags=re.I)
        if m:
            number = int(next(g for g in m.groups() if g))

        inline_url = None
        full_url = None
        for img in fig_div.select("img"):
            src = img.get("data-image-src") or img.get("src")
            abs_src = absolute_url(src, page_url)
            if not abs_src:
                continue
            if "full-" in abs_src and not full_url:
                full_url = abs_src
            elif "inline-" in abs_src and not inline_url:
                inline_url = abs_src
            elif not inline_url:
                inline_url = abs_src

        download_a = fig_div.select_one('li.download-figure a[download][href], a[download][href*=".figure."]')
        image_download_url = absolute_url(download_a.get("href"), page_url) if download_a else None

        caption_wrapper = fig_div.select_one(".figure-text-wrapper") or fig_div
        caption_parts: list[str] = []
        if label:
            caption_parts.append(label)
        citation_text = None
        for p in caption_wrapper.find_all("p", recursive=False):
            t = text_of(p)
            if not t:
                continue
            if "citation" in p.get("class", []):
                citation_text = t
            else:
                caption_parts.append(t)

        alt_text = None
        img_alt = fig_div.select_one("img[alt]")
        if img_alt:
            alt_text = clean_text(img_alt.get("alt"))
        ppt_a = fig_div.select_one("a.export-figure-ppt[alt-text]")
        if ppt_a and ppt_a.get("alt-text"):
            alt_text = clean_text(ppt_a.get("alt-text")) or alt_text

        figures.append(
            {
                "figure_number": number,
                "figure_id": fig_id,
                "label": label,
                "image_url_inline": inline_url,
                "image_url_full": full_url,
                "image_download_url": image_download_url,
                "descripcion_figura": "\n".join(caption_parts) if caption_parts else None,
                "citation": citation_text,
                "alt_text": alt_text,
            }
        )

    figures.sort(key=lambda f: (f["figure_number"] is None, f["figure_number"] or 9999))
    return figures


def extract_footnotes(body: Optional[Tag]) -> list[dict[str, Optional[str]]]:
    if body is None:
        return []
    footnotes: list[dict[str, Optional[str]]] = []
    for fn in body.select(".footnoteGroup .footnote"):
        label = text_of(fn.select_one(".label"))
        text = text_of(fn.select_one("p"))
        footnotes.append({"label": label, "text": text})
    return footnotes


def extract_references(body: Optional[Tag], page_url: str) -> list[dict[str, Any]]:
    if body is None:
        return []
    ref_section = body.select_one("section.refSection")
    if ref_section is None:
        ref_section = find_section(body, "References")
    if ref_section is None:
        return []

    refs: list[dict[str, Any]] = []
    for ref in ref_section.select("div.reference"):
        number = text_of(ref.select_one(".label"))
        citation_p = ref.select_one("p.citationText")
        full_citation = text_of(citation_p)

        citation_links: list[dict[str, Optional[str]]] = []
        if citation_p:
            for a in citation_p.select("a[href]"):
                citation_links.append({"label": text_of(a), "url": absolute_url(a.get("href"), page_url)})

        crossref_url = None
        google_scholar_url = None
        export_citation_url = None
        action_links: list[dict[str, Optional[str]]] = []
        for a in ref.select("ul.citationActions a[href]"):
            label = text_of(a) or ""
            href = absolute_url(a.get("href"), page_url)
            action_links.append({"label": label, "url": href})
            low = normalize_for_match(label)
            classes = " ".join(a.get("class", []))
            if "crossref" in low or "doi" in classes.lower():
                crossref_url = href
            elif "google scholar" in low or "googlescholar" in classes.lower():
                google_scholar_url = href
            elif "export" in low or "exportcitation" in classes.lower():
                export_citation_url = href

        refs.append(
            {
                "number": number,
                "full_citation": full_citation,
                "authors": text_of(ref.select_one(".person-group")),
                "article_title": text_of(ref.select_one(".article-title")),
                "journal_or_source": text_of(ref.select_one("i")),
                "year": text_of(ref.select_one(".year")),
                "external_urls_in_citation": citation_links,
                "crossref_url": crossref_url,
                "google_scholar_url": google_scholar_url,
                "export_citation_url": export_citation_url,
                "action_links": action_links,
            }
        )

    return refs


def extract_pdf_url(soup: BeautifulSoup, page_url: str) -> Optional[str]:
    pdf = meta_content(soup, name="citation_pdf_url")
    if pdf:
        return absolute_url(pdf, page_url)
    a = soup.select_one('a.pdf-download[href], a[title="Download PDF"][href], a[href*="/downloadpdf/"]')
    return absolute_url(a.get("href"), page_url) if a else None


def extract_article(html: str, page_url: str) -> dict[str, Any]:
    soup = BeautifulSoup(html, "lxml")
    body = article_body(soup)

    canonical = None
    canonical_link = soup.find("link", rel=lambda x: x and "canonical" in x)
    if canonical_link and canonical_link.get("href"):
        canonical = absolute_url(canonical_link.get("href"), page_url)
    article_url = strip_query_and_fragment(canonical or meta_content(soup, prop="og:url") or page_url)

    title = meta_content(soup, name="citation_title") or meta_content(soup, prop="og:title")
    editorial_type = extract_definition_value(soup, "editorialType")

    article = {
        "title": title,
        "editorial_type": editorial_type,
        "article_url": article_url,
        "doi": meta_content(soup, name="citation_doi") or meta_content(soup, name="dc.identifier"),
        "journal": meta_content(soup, name="citation_journal_title"),
        "publication_date": meta_content(soup, name="citation_publication_date")
        or meta_content(soup, prop="article:published_time")
        or extract_definition_value(soup, "onlinepubdate"),
        "volume": meta_content(soup, name="citation_volume"),
        "issue": meta_content(soup, name="citation_issue"),
        "pages": build_pages(
            meta_content(soup, name="citation_firstpage"),
            meta_content(soup, name="citation_lastpage"),
            extract_definition_value(soup, "pagerange"),
        ),
        "pdf_original_url": extract_pdf_url(soup, page_url),
        "autores": extract_authors(soup),
        "descripcion_del_caso": extract_case_description(body),
        "interpretacion_ecg": extract_section_text(body, "ECG Interpretation", include_heading=False),
        "figuras": extract_figures(body, page_url),
        "discusion": extract_section_text(body, "Discussion", include_heading=True),
        "notas_pie": extract_footnotes(body),
        "referencias": extract_references(body, page_url),
    }

    # Campos planos figura_1, descripcion_figura_1, figura_2... ademas del array "figuras".
    for fig in article["figuras"]:
        n = fig.get("figure_number")
        if n is None:
            continue
        article[f"figura_{n}"] = fig.get("image_download_url") or fig.get("image_url_full") or fig.get("image_url_inline")
        article[f"descripcion_figura_{n}"] = fig.get("descripcion_figura")

    return article


def build_pages(first: Optional[str], last: Optional[str], visible: Optional[str]) -> Optional[str]:
    if visible:
        return visible
    if first and last and first != last:
        return f"{first}-{last}"
    return first or last


def is_ecg_of_the_month(article: dict[str, Any]) -> bool:
    haystack = " | ".join(
        str(article.get(k) or "") for k in ("title", "editorial_type")
    ).lower()
    return "ecg of the month" in haystack


def save_json(path: Path, data: dict[str, Any]) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(json.dumps(data, ensure_ascii=False, indent=2), encoding="utf-8")


def scrape_all(args: argparse.Namespace) -> dict[str, Any]:
    session = make_session(args.cookies)
    errors: list[dict[str, str]] = []
    article_links: list[str] = []

    for page in range(args.page_start, args.page_end + 1):
        page_url = SEARCH_URL_TEMPLATE.format(page=page)
        try:
            print(f"[busqueda] pagina {page}: {page_url}", file=sys.stderr)
            html = fetch(session, page_url, timeout=args.timeout, delay=args.delay).html
            links = collect_article_links_from_search_html(html, page_url)
            print(f"  enlaces candidatos: {len(links)}", file=sys.stderr)
            article_links.extend(links)
        except Exception as exc:
            msg = str(exc)
            print(f"  ERROR: {msg}", file=sys.stderr)
            errors.append({"stage": "search", "url": page_url, "error": msg})

    article_links = dedupe_preserve_order(article_links)
    if args.limit:
        article_links = article_links[: args.limit]

    data: dict[str, Any] = {
        "source_url": SEARCH_URL_TEMPLATE.format(page=args.page_start),
        "page_start": args.page_start,
        "page_end": args.page_end,
        "generated_at": dt.datetime.now(dt.timezone.utc).isoformat(),
        "total_candidate_links": len(article_links),
        "articles": [],
        "errors": errors,
    }

    for idx, url in enumerate(article_links, start=1):
        try:
            print(f"[articulo {idx}/{len(article_links)}] {url}", file=sys.stderr)
            html = fetch(session, url, timeout=args.timeout, delay=args.delay).html
            article = extract_article(html, url)
            if not args.keep_non_ecg and not is_ecg_of_the_month(article):
                print("  omitido: no parece ECG of the Month", file=sys.stderr)
                continue
            data["articles"].append(article)
            # Guardado incremental por seguridad.
            save_json(Path(args.output), data)
        except Exception as exc:
            msg = str(exc)
            print(f"  ERROR: {msg}", file=sys.stderr)
            data["errors"].append({"stage": "article", "url": url, "error": msg})
            save_json(Path(args.output), data)

    data["total_articles_extracted"] = len(data["articles"])
    save_json(Path(args.output), data)
    return data


def parse_local_html(args: argparse.Namespace) -> dict[str, Any]:
    html_path = Path(args.html_file)
    html = html_path.read_text(encoding=args.encoding, errors="replace")
    article = extract_article(html, args.article_url or BASE_URL)
    data = {
        "source_url": str(html_path),
        "generated_at": dt.datetime.now(dt.timezone.utc).isoformat(),
        "total_articles_extracted": 1,
        "articles": [article],
        "errors": [],
    }
    save_json(Path(args.output), data)
    return data


def build_argparser() -> argparse.ArgumentParser:
    parser = argparse.ArgumentParser(
        description="Extrae ECG of the Month de AVMA Journals a JSON.",
        formatter_class=argparse.ArgumentDefaultsHelpFormatter,
    )
    parser.add_argument("--output", default="ecg_of_the_month.json", help="Archivo JSON de salida")
    parser.add_argument("--page-start", type=int, default=1, help="Primera pagina de busqueda")
    parser.add_argument("--page-end", type=int, default=36, help="Ultima pagina de busqueda")
    parser.add_argument("--timeout", type=int, default=30, help="Timeout HTTP en segundos")
    parser.add_argument("--delay", type=float, default=0.8, help="Pausa entre peticiones HTTP")
    parser.add_argument("--limit", type=int, default=0, help="Limita el numero de articulos, 0 = sin limite")
    parser.add_argument("--cookies", default=None, help="Cabecera Cookie copiada del navegador")
    parser.add_argument(
        "--keep-non-ecg",
        action="store_true",
        help="No descarta articulos cuyo title/editorial_type no sea ECG of the Month",
    )
    parser.add_argument("--html-file", default=None, help="HTML local de un articulo para probar el parser")
    parser.add_argument("--article-url", default=None, help="URL base/canonica si se usa --html-file")
    parser.add_argument("--encoding", default="utf-8", help="Codificacion para --html-file")
    return parser


def main() -> None:
    parser = build_argparser()
    args = parser.parse_args()

    if args.page_start < 1 or args.page_end < args.page_start:
        parser.error("Rango de paginas no valido")

    if args.html_file:
        data = parse_local_html(args)
    else:
        data = scrape_all(args)

    print(
        f"OK: {data.get('total_articles_extracted', len(data.get('articles', [])))} articulos guardados en {args.output}",
        file=sys.stderr,
    )


if __name__ == "__main__":
    main()
