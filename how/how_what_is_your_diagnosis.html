Cómo se extrae la información de “What Is Your Diagnosis?”

Desarrollado por: Ángel Soto

🏠 volver a página de inicio

Esta página documenta el proceso de extracción automatizada de artículos de AVMA Journals tipo What Is Your Diagnosis? y variantes como What Is Your Neurologic Diagnosis?. El objetivo es convertir cada entrada en un JSON estructurado con autores, historia clínica, secciones diagnósticas, figuras, PDF y referencias.

Ver script Python

Referencia de origen

La fuente es la búsqueda pública de AVMA Journals, filtrada por la consulta what is your diagnosis. El script recorre páginas de resultados y abre cada artículo candidato para analizar su HTML interno.

🔎 Búsqueda AVMA 📄 Ejemplo de artículo 🧬 HTML + metadatos citation_* 🖼️ Figuras incluidas

Uso previsto

El extractor está pensado para generar un archivo what_is_your_diagnosis.json con fines docentes y de organización de casos. Si el sitio requiere acceso institucional, el script usa una sesión de navegador local autorizada mediante Playwright.

No elimina restricciones de acceso: usa la sesión que el usuario tenga disponible en su navegador.

Qué datos se extraen

tituloNombre real del artículo: “What Is Your Diagnosis?”, “What Is Your Neurologic Diagnosis?”, etc.
autoresLista de autores y credenciales visibles en el bloque de contribuyentes.
historia_clinicaTexto de la sección History, con signos clínicos, exploración y pruebas iniciales.
figurasTodas las imágenes detectadas, con URL, texto de figura, alt-text y enlace de descarga.
pdfEnlace directo al PDF del artículo obtenido desde citation_pdf_url o desde el botón “Download PDF”.
seccionesTodos los encabezados h2 del cuerpo del artículo, incluso si cambian según la especialidad.
comentariosTexto de la sección Comments cuando existe.
referenciasCitas bibliográficas con enlaces a Google Scholar y Export Citation.

Cómo funciona el script

Genera URLs de búsquedaConstruye las páginas 1 a 100 usando q3=what is your diagnosis.
Abre la web con PlaywrightUsa Chromium y una carpeta de perfil local para conservar cookies y acceso institucional.
Detecta enlaces candidatosExtrae URLs de artículos desde enlaces del DOM y también mediante regex sobre el HTML crudo.
Valida el títuloComprueba que citation_title encaje con el patrón “What Is Your … Diagnosis?”.
Lee metadatos académicosUsa etiquetas citation_title, citation_pdf_url, citation_doi, volumen, número y páginas.
Parsea el cuerpo clínicoBusca #articleBody y recorre secciones, figuras y referencias.
Guarda de forma incrementalActualiza el JSON tras cada artículo, de modo que puede reanudarse si se interrumpe.

Campos variables

No todos los artículos usan exactamente los mismos encabezados. En radiología suele aparecer Radiographic Findings and Interpretation, pero en neurología u otras series puede cambiar.

Por eso el script no depende de un único título fijo: guarda todas las secciones h2 en el objeto secciones y además crea accesos directos cuando reconoce nombres frecuentes.

Figuras e imágenes

Cada bloque div.figure puede contener una imagen inline, una imagen full-size y un enlace de descarga. El extractor prioriza el enlace descargable y normaliza la URL para que quede absoluta.

También extrae el pie de figura, por ejemplo Figure 1—, y el texto descriptivo asociado.

Script Python completo

Código preparado para extraer los artículos, guardar el JSON incremental y conservar enlaces de figuras, PDF, Google Scholar y Export Citation.

avma_diagnosis_scraper.py

Ejecución local

Instalar dependencias 
pip install beautifulsoup4 lxml playwright
python -m playwright install chromium
Primera ejecución con navegador visible 
python avma_diagnosis_scraper.py --headed --pause-for-login
Ejecuciones posteriores 
python avma_diagnosis_scraper.py --start-page 1 --end-page 100 --output what_is_your_diagnosis.json
