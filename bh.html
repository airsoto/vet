Notas: Modelo educativo (agujero negro no rotante). Se usa dilatación gravitatoria de Schwarzschild: dτ = dt · √(1 − rs/r). La dilatación por velocidad (SR) se añade opcionalmente con √(1 − β²). Ignora efectos de rotación (Kerr), mareas, dinámica real de caída libre, etc.
rs = 2GM/c². Para M87*, M ≈ 6.5×10⁹ M☉ ⇒ rs ≈ 1.92×10¹³ m ≈ 1.92×10¹⁰ km ≈ 128 AU.

Información y fórmulas

Este simulador ilustra la dilatación temporal cerca de un agujero negro no rotante (métrica de Schwarzschild) como la sombra de M87*.

Fórmulas

  • Radio de Schwarzschild: r_s = 2GM/c^2.
  • Dilatación gravitatoria para un reloj estacionario a distancia r:
    dτ = dt · √(1 − r_s/r).
  • Dilatación por velocidad (Relatividad Especial, opcional): √(1 − β²), con β=v/c.
  • Modelo combinado usado aquí: dτ/dt = √(1 − r_s/r) · √(1 − β²) (la parte SR es opcional).

Nota: Para un observador “estacionario” muy cerca del horizonte se requiere una aceleración enorme (no física en el límite). En este modelo educativo permitimos acercarse hasta r = r_s, donde formalmente dτ/dt → 0 para ese reloj.

Parámetros de M87*

  • Masa aproximada: 6.5×10⁹ masas solares.
  • r_s mostrado arriba (km y AU) se calcula con esos valores nominales.

Controles

  • Rueda ratón: acercar/alejar (cambia r/rs).
  • Arrastrar astronauta: mover sobre el rail.
  • Mantener pulsado cerca del BH: “tirar” hacia el horizonte.
  • Botones: ⏸️ Pausar, ⏬ Acercar (auto hasta el horizonte), 🔁 Reset.
  • Velocidad de simulación: multiplica el paso temporal de ambos relojes.

Limitaciones

  • No incluye rotación (Kerr), luz curva real, ni dinámica de caída libre; es una visualización didáctica.
  • El “tiempo externo” representa un reloj lejano al BH (espacio asintóticamente plano).
