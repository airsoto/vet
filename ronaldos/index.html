Cómo funciona el juego

Esta aplicación está construida en un único archivo HTML que contiene la estructura, los estilos CSS, la lista JSON de canciones y la programación JavaScript.

  1. Cada partida selecciona ocho canciones al azar.
  2. Cada ronda reproduce automáticamente el primer segundo del archivo MP3.
  3. El botón Añadir 1 segundo prolonga el fragmento y lo vuelve a reproducir.
  4. El premio máximo comienza en 1 punto y disminuye 0,2 puntos por cada segundo añadido.
  5. La puntuación queda en 0 a partir de seis segundos.
  6. Al escribir tres letras aparecen canciones coincidentes que pueden seleccionarse.
  7. Si se solicitan tres opciones, un acierto vale 0,5 puntos.
  8. Los archivos MP3 deben estar dentro de la subcarpeta canciones.
