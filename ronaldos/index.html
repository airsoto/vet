Cómo está creado este juego

Esta aplicación está construida en un único archivo HTML que incluye la estructura, los estilos CSS y la programación JavaScript.

  1. Las canciones se almacenan en una lista JSON incluida en el propio documento.
  2. JavaScript baraja el orden de las canciones al comenzar cada partida.
  3. Cada ronda reproduce automáticamente el primer segundo del archivo MP3.
  4. El jugador puede repetir ese mismo fragmento tantas veces como necesite.
  5. Un acierto escribiendo el título vale 1 punto.
  6. Si se solicitan tres opciones, un acierto vale 0,5 puntos.
  7. Los archivos MP3 deben estar dentro de la subcarpeta canciones.

El botón de información contiene únicamente la explicación técnica del juego. No se incluye un descargador de YouTube, porque esa función requeriría un servidor externo y debe respetar los derechos de autor y las condiciones del servicio.
