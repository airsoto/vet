¿Qué hace el algoritmo de Shor?

Resumen explicado

El algoritmo de Shor es un algoritmo cuántico para encontrar factores de un número entero transformando el problema de factorización en otro problema: encontrar el período u orden de una función modular.

La idea central

Se elige un número a menor que N. Primero se calcula mcd(a,N). Si ese máximo común divisor es mayor que 1, ya hemos encontrado un factor de N.

Si a y N son coprimos, se estudia la función:

f(x) = aˣ mod N

Como los restos módulo N se repiten, existe un período r: el menor entero positivo que cumple:

aʳ ≡ 1 (mod N)

¿Dónde aparece la computación cuántica?

La aceleración de Shor está en encontrar ese período. El procedimiento cuántico prepara una superposición de estados, evalúa la función modular y aplica una Transformada Cuántica de Fourier (QFT). La medición ofrece información desde la que se recupera un candidato al período r.

Cómo salen los factores

Si r es par y aʳᐟ² no es congruente con −1 módulo N, entonces:

aʳ − 1 = (aʳᐟ² − 1)(aʳᐟ² + 1)

y los factores no triviales pueden aparecer al calcular:

p = mcd(aʳᐟ² − 1, N)
q = mcd(aʳᐟ² + 1, N)

Si r es impar, si se obtiene el caso −1, o si los MCD son triviales, se escoge otro valor de a y se repite. Por eso el algoritmo es probabilístico.

Por qué es importante

La relevancia criptográfica de Shor es que una computadora cuántica suficientemente capaz podría factorizar eficientemente enteros grandes. RSA basa buena parte de su seguridad en la dificultad práctica de factorizar un número N que es producto de dos primos grandes.

Qué representa esta web

Aquí las partes clásicas son reales y el período r se busca mediante cálculo modular convencional. Es decir, se visualiza la lógica de Shor, pero se sustituye el subprograma cuántico por una simulación clásica para que todo pueda ejecutarse en el navegador.
