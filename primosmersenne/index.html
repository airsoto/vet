Para exponentes grandes se muestra la forma Mp = 2p − 1 sin convertir todo el número a decimal. No existe un límite artificial de tamaño: puedes introducir exponentes muy grandes. El cálculo puede tardar mucho tiempo, consumir gran cantidad de memoria o ser interrumpido por el navegador.

¿Qué es un número de Mersenne?

Un número de Mersenne es un número entero de la forma:

Mp = 2p − 1

Por ejemplo, si p = 5:

M5 = 25 − 1 = 31

Para que un número de Mersenne pueda ser primo, su exponente p debe ser primo. Esto permite descartar inmediatamente cualquier exponente compuesto. Sin embargo, que p sea primo no garantiza que Mp también lo sea: por ejemplo, 11 es primo pero 211 − 1 = 2047 = 23 × 89.

Cuando p es primo, esta web utiliza el test de Lucas–Lehmer, específico para números de Mersenne. Empieza con s = 4 y repite:

s ← s² − 2   (mod Mp)

Después de p − 2 iteraciones, Mp es primo exactamente cuando el resultado es 0. La implementación utiliza enteros BigInt, reducción modular adaptada a números de Mersenne y un Web Worker para evitar bloquear la página.

Nota: no se impone un límite artificial al exponente. Los valores enormes pueden exigir muchísimo tiempo y memoria, y el navegador o el sistema operativo pueden llegar a interrumpir el cálculo. La herramienta permite intentarlo bajo responsabilidad del usuario.

Implementación en Python

La búsqueda o comprobación de un primo de Mersenne también puede implementarse localmente en Python utilizando gmpy2, que emplea aritmética optimizada para enteros grandes.

Python · Lucas–Lehmer con gmpy2 
#sudo apt update
#sudo apt install python3-gmpy2

import gmpy2
from time import perf_counter

def lucas_lehmer(p):
    if p == 2:
        return True

    if not gmpy2.is_prime(p):
        print(f"El exponente {p} no es primo.")
        return False

    M = gmpy2.mpz(2) ** p - 1
    s = gmpy2.mpz(4)

    total = p - 2
    inicio = perf_counter()

    for i in range(total):
        s = (s * s - 2) % M

        if i % 1000 == 0 or i == total - 1:
            transcurrido = perf_counter() - inicio
            porcentaje = 100 * (i + 1) / total

            if i > 0:
                velocidad = (i + 1) / transcurrido
                restante = (total - i - 1) / velocidad
            else:
                velocidad = 0
                restante = 0

            print(
                f"\r{porcentaje:6.2f}% | "
                f"{i+1:,}/{total:,} | "
                f"{velocidad:,.1f} iter/s | "
                f"restante ≈ {restante:,.1f} s",
                end="",
                flush=True
            )

    tiempo = perf_counter() - inicio

    print(f"\nTiempo total: {tiempo:.3f} s")

    return s == 0


# -----------------------------------------
# PROGRAMA PRINCIPAL
# -----------------------------------------

p = int(input("Introduce el exponente p: "))

print()
print(f"M{p} = 2^{p} - 1")
print("Comprobando primalidad...")
print()

inicio_total = perf_counter()

resultado = lucas_lehmer(p)

tiempo_total = perf_counter() - inicio_total

print()

if resultado:
    print("✅ ES UN PRIMO DE MERSENNE")
else:
    print("❌ NO ES UN PRIMO DE MERSENNE")

print(f"Tiempo empleado: {tiempo_total:.3f} s")

Para exponentes muy grandes, programas especializados pueden superar ampliamente esta implementación al utilizar multiplicación y reducción modular altamente optimizadas, incluidas técnicas basadas en FFT.

Mayor número primo conocido

Récord vigente verificado por GIMPS
2136.279.841 − 1
41.024.320 dígitos decimales
Descubierto el 12 de octubre de 2024 por Luke Durant dentro de la Gran Búsqueda de Primos de Mersenne en Internet (GIMPS).

El mayor número primo conocido es el mayor entero que se ha demostrado que es primo. Esto no significa que sea el mayor primo existente: Euclides demostró que existen infinitos números primos, por lo que siempre hay primos mayores.

La computación electrónica aceleró enormemente la búsqueda de récords. Los primos de Mersenne son especialmente importantes porque el test de Lucas–Lehmer permite comprobar su primalidad de manera muy eficiente en comparación con pruebas generales aplicadas a números de tamaño similar.

GIMPS distribuye estos cálculos entre ordenadores aportados por participantes de todo el mundo. La Electronic Frontier Foundation (EFF) ha patrocinado premios para hitos de tamaño: el récord de más de un millón de dígitos obtuvo 50.000 US$ y el de más de diez millones obtuvo 100.000 US$. Siguen contemplados premios para primos de al menos cien millones y mil millones de dígitos.
