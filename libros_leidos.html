Cómo funciona este buscador

Filtros, ordenación y cálculo del tiempo de lectura.

Esta web carga una lista de libros desde un JSON embebido (variable BOOKS). Puedes filtrar por título, autor y género, y ordenar los resultados.

Formato del JSON

Cada libro usa campos como: titulo, autor, detalles, cover_image_url, num_pag, puntuación que le he dado y genero (array).

Tiempo de lectura

Se estima con una velocidad en palabras por minuto (WPM) (200/250/300/350) y una aproximación de 300 palabras por página (configurable en el código).

Fórmula usada: minutos = (páginas × palabrasPorPágina) / WPM.

Personalización rápida

  • Para añadir libros: agrega objetos al array BOOKS.
  • Para cambiar la aproximación: modifica WORDS_PER_PAGE.
  • La velocidad elegida se guarda en localStorage.
