Documentación — Cornell Consultant → JSON

Cómo está hecho el programa

Este documento describe el flujo del scraper: cómo toma una lista de códigos de signos, construye las URLs, extrae los diagnósticos diferenciales desde el HTML y genera un JSON. No ejecuta nada: es solo explicación + el código Python visible en una “ventana”.

Entrada: sings_link.txt URL: ...?signs=1-XXX Salida: consultant_signs_canine.json

1) Fuente de códigos y “Proceso”

El programa parte de un archivo de texto (sings_link.txt) donde cada línea contiene: código (tres caracteres tras SX_, p.ej. A00, C0A, DE3) y, a continuación, el nombre del proceso (p.ej. “Deafness”). Ese texto se asigna directamente al campo "Proceso" en el JSON.

Detalle: el script acepta separación por TAB (\t) y también por 2+ espacios como respaldo.

2) Construcción de la URL de consulta

Para cada código, se genera una URL con el patrón: https://consultant.vet.cornell.edu/?Fun=F_Sign&spc=Canine&dxkw=&sxkw=&signs=1-XXX. El programa sustituye XXX por el código (por ejemplo, A00), y descarga el HTML resultante.

Buenas prácticas: el script usa requests.Session() y una pausa (sleep) entre peticiones para evitar saturar el servidor.

3) Extracción de “Diagnósticos diferenciales”

En la página, la lista de “Possible Diagnoses” se presenta como enlaces <a class="news">...</a>. El programa filtra únicamente los enlaces cuyo href contiene Fun=Cause_, y guarda el texto visible de cada enlace como un elemento de la lista "Diagnósticos diferenciales".

Detalle: se eliminan duplicados conservando el orden para que el JSON sea estable.

4) Campo “especialidades”

El campo "especialidades" se infiere de la primera letra del código: A=Acoustic, C=Cardiovascular, D=Digestive, E=Ophthalmology, G=General, M=Musculoskeletal, N=Nervous, P=Pain/Discomfort, R=Respiratory, S=Skin/Integumentary, T=Reproductive, U=Urinary. Si no encaja, se usa "All".

scrape_consultant_signs.py 
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
Scraper Cornell Consultant: Signs -> Possible Diagnoses (Canine)

Input:  sings_link.txt  (CODEPROCESS)  e.g. "A00\tDeafness"
Output: consultant_signs_canine.json

Notes:
- "Proceso" is taken from the txt (per instruction), not from the page.
- "especialidades" is inferred from the first character of the code.
- "Diagnósticos diferenciales" are extracted from  whose href contains "Fun=Cause_".
"""

import json
import re
import time
from dataclasses import dataclass
from typing import Dict, List, Tuple

import requests
from bs4 import BeautifulSoup


BASE_URL = "https://consultant.vet.cornell.edu/"
URL_TMPL = BASE_URL + "?Fun=F_Sign&spc=Canine&dxkw=&sxkw=&signs=1-{code}"

INPUT_TXT = "sings_link.txt"
OUTPUT_JSON = "consultant_signs_canine.json"

SYSTEM_MAP: Dict[str, str] = {
    "A": "Acoustic",
    "C": "Cardiovascular",
    "D": "Digestive",
    "E": "Ophthalmology",
    "G": "General",
    "M": "Musculoskeletal",
    "N": "Nervous",
    "P": "Pain/Discomfort",
    "R": "Respiratory",
    "S": "Skin/Integumentary",
    "T": "Reproductive",
    "U": "Urinary",
}

SLEEP_SECONDS = 0.6
TIMEOUT = 25


@dataclass
class SignRow:
    code: str
    proceso: str


def read_signs_txt(path: str) -> List[SignRow]:
    rows: List[SignRow] = []
    with open(path, "r", encoding="utf-8", errors="replace") as f:
        for raw in f:
            line = raw.strip()
            if not line:
                continue
            parts = re.split(r"\t+", line, maxsplit=1)
            if len(parts) < 2:
                parts = re.split(r"\s{2,}", line, maxsplit=1)
            if len(parts) < 2:
                continue
            code = parts[0].strip()
            proceso = parts[1].strip()
            if not code or not proceso:
                continue
            rows.append(SignRow(code=code, proceso=proceso))
    return rows


def infer_system(code: str) -> str:
    if not code:
        return "All"
    return SYSTEM_MAP.get(code[0].upper(), "All")


def fetch_html(session: requests.Session, url: str, retries: int = 3) -> str:
    last_err = None
    for attempt in range(1, retries + 1):
        try:
            r = session.get(url, timeout=TIMEOUT)
            r.raise_for_status()
            r.encoding = r.apparent_encoding or "utf-8"
            return r.text
        except Exception as e:
            last_err = e
            time.sleep(0.8 * attempt)
    raise RuntimeError(f"Failed to fetch after {retries} attempts: {url}\nLast error: {last_err}")


def extract_diagnoses(html: str) -> List[str]:
    soup = BeautifulSoup(html, "html.parser")
    anchors = soup.select("a.news")

    diags: List[str] = []
    seen = set()

    for a in anchors:
        href = a.get("href", "") or ""
        if "Fun=Cause_" not in href:
            continue
        text = a.get_text(" ", strip=True)
        if not text:
            continue
        if text in seen:
            continue
        seen.add(text)
        diags.append(text)

    return diags


def main() -> None:
    signs = read_signs_txt(INPUT_TXT)
    if not signs:
        raise SystemExit(f"No valid rows found in {INPUT_TXT}")

    session = requests.Session()
    session.headers.update({
        "User-Agent": "Mozilla/5.0 (X11; Linux x86_64) CornellConsultantScraper/1.0 (+non-commercial research)",
        "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8",
        "Accept-Language": "en-US,en;q=0.9",
        "Connection": "keep-alive",
    })

    out: List[dict] = []
    errors: List[Tuple[str, str]] = []

    for i, row in enumerate(signs, start=1):
        url = URL_TMPL.format(code=row.code)
        try:
            html = fetch_html(session, url)
            diags = extract_diagnoses(html)
            entry = {
                "Proceso": row.proceso,
                "especialidades": infer_system(row.code),
                "Diagnósticos diferenciales": diags,
                "meta": {"sign_code": row.code, "url": url},
            }
            out.append(entry)
        except Exception as e:
            errors.append((row.code, str(e)))

        time.sleep(SLEEP_SECONDS)
        if i % 25 == 0:
            print(f"Progress: {i}/{len(signs)}")

    payload = {
        "source": "consultant.vet.cornell.edu",
        "species": "Canine",
        "generated_from": INPUT_TXT,
        "count": len(out),
        "items": out,
        "errors": [{"code": c, "error": msg} for c, msg in errors],
    }

    with open(OUTPUT_JSON, "w", encoding="utf-8") as f:
        json.dump(payload, f, ensure_ascii=False, indent=2)

    print(f"Saved: {OUTPUT_JSON}  (items={len(out)}, errors={len(errors)})")


if __name__ == "__main__":
    main()
