How to use this view

  • Filter processes by specialty or search by process name.
  • Select multiple processes to reveal shared differential diagnoses.
  • Use Shared only for the cleanest overlap-focused graph.
  • Use All related to show all diagnoses associated with the selected processes.
  • The frequency panel shows which diagnoses appear in 1, 2, 3, 4, 5, etc. selected processes.
  • Drag nodes, zoom, and pan freely in the graph.
