Scraper Cornell Consultant → JSON

Signs/Symptoms (Canine) → Lista de diagnósticos por signo

modo: dark
Automatización de extracción: Sign → Possible Diagnoses

Objetivo del programa

Este programa genera un JSON estructurado a partir del buscador de signos de Cornell Consultant, para que cada signo (proceso) quede asociado a su lista de diagnósticos diferenciales. La clave es que el código del signo (XXX) se toma de un archivo de texto y se inserta en la URL de consulta: ...?signs=1-XXX.

Entrada: sings_link.txt (código + proceso) Salida: consultant_signs_canine.json Extracción: enlaces <a class="news"> con Fun=Cause_

Cómo funciona (paso a paso)

  • El archivo sings_link.txt contiene, en cada línea, el código del signo (p.ej. A00, C0A, DE3) y, a continuación, el proceso (texto que irá en el campo "Proceso").
  • Para cada código, el script construye la URL: https://consultant.vet.cornell.edu/?Fun=F_Sign&spc=Canine&dxkw=&sxkw=&signs=1-XXX
  • Descarga el HTML y extrae los diagnósticos diferenciales desde los enlaces: <a class="news"> cuyo href contiene Fun=Cause_.
  • Opcionalmente, asigna "especialidades" inferida por la primera letra del código (A=Acoustic, C=Cardiovascular, D=Digestive, etc.).
  • Escribe un JSON final con objetos del tipo: { "Proceso": "...", "especialidades": "...", "Diagnósticos diferenciales": [...] }
Nota: el campo "Proceso" se toma del TXT (no del HTML), exactamente como pediste: “el proceso será el nombre que aparece un espacio detrás del código”.

Comandos rápidos

Terminal pip / ejecución 
pip install requests beautifulsoup4
python3 scrape_consultant_signs.py

Formato de entrada esperado

Ejemplos de líneas válidas en sings_link.txt:

sings_link.txt CODE<TAB>PROCESS 
A00	Deafness
C0A	Atrial, supraventricular, premature beat
DE3	Gagging, retching
Si en tu archivo no hay tabulador, el script también acepta separación por 2+ espacios.

Salida JSON

Ejemplo de un elemento:

consultant_signs_canine.json estructura 
{
  "Proceso": "Deafness",
  "especialidades": "Acoustic",
  "Diagnósticos diferenciales": [
    "Anaphylaxis, overdose, drug, vaccine, radiation, reaction, side effects, toxicity",
    "Beta mannosidosis canine"
  ]
}
Importante: el script filtra enlaces class="news" con Fun=Cause_, que en la página corresponden a “Possible Diagnoses”.

Script Python

Este es el código completo del scraper. Puedes copiarlo tal cual a scrape_consultant_signs.py.

scrape_consultant_signs.py requests + BeautifulSoup 
#!/usr/bin/env python3
# -*- coding: utf-8 -*-

"""
Scraper Cornell Consultant: Signs -> Possible Diagnoses (Canine)

Input:  sings_link.txt  (CODE<TAB>PROCESS)  e.g. "A00\tDeafness"
Output: consultant_signs_canine.json

Notes:
- "Proceso" is taken from the txt (per your instruction), not from the page.
- "especialidades" is inferred from the first character of the code.
- "Diagnósticos diferenciales" are extracted from <a class="news"> whose href contains "Fun=Cause_".
"""

import json
import re
import time
from dataclasses import dataclass
from typing import Dict, List, Tuple

import requests
from bs4 import BeautifulSoup


BASE_URL = "https://consultant.vet.cornell.edu/"
URL_TMPL = BASE_URL + "?Fun=F_Sign&spc=Canine&dxkw=&sxkw=&signs=1-{code}"

INPUT_TXT = "sings_link.txt"
OUTPUT_JSON = "consultant_signs_canine.json"

# Map first char of code -> system/specialty (as per your system dropdown)
SYSTEM_MAP: Dict[str, str] = {
    "A": "Acoustic",
    "C": "Cardiovascular",
    "D": "Digestive",
    "E": "Ophthalmology",
    "G": "General",
    "M": "Musculoskeletal",
    "N": "Nervous",
    "P": "Pain/Discomfort",
    "R": "Respiratory",
    "S": "Skin/Integumentary",
    "T": "Reproductive",
    "U": "Urinary",
}

# polite scraping
SLEEP_SECONDS = 0.6
TIMEOUT = 25


@dataclass
class SignRow:
    code: str       # e.g. "A00", "C0A", "DE3"
    proceso: str    # e.g. "Deafness"


def read_signs_txt(path: str) -> List[SignRow]:
    rows: List[SignRow] = []
    with open(path, "r", encoding="utf-8", errors="replace") as f:
        for raw in f:
            line = raw.strip()
            if not line:
                continue
            # expected: CODE<TAB>PROCESS (but accept multiple spaces too)
            parts = re.split(r"\t+", line, maxsplit=1)
            if len(parts) < 2:
                parts = re.split(r"\s{2,}", line, maxsplit=1)  # fallback: 2+ spaces
            if len(parts) < 2:
                # skip malformed lines
                continue
            code = parts[0].strip()
            proceso = parts[1].strip()
            if not code or not proceso:
                continue
            rows.append(SignRow(code=code, proceso=proceso))
    return rows


def infer_system(code: str) -> str:
    if not code:
        return "All"
    return SYSTEM_MAP.get(code[0].upper(), "All")


def fetch_html(session: requests.Session, url: str, retries: int = 3) -> str:
    last_err = None
    for attempt in range(1, retries + 1):
        try:
            r = session.get(url, timeout=TIMEOUT)
            r.raise_for_status()
            r.encoding = r.apparent_encoding or "utf-8"
            return r.text
        except Exception as e:
            last_err = e
            # backoff
            time.sleep(0.8 * attempt)
    raise RuntimeError(f"Failed to fetch after {retries} attempts: {url}\nLast error: {last_err}")


def extract_diagnoses(html: str) -> List[str]:
    soup = BeautifulSoup(html, "html.parser")

    # anchor targets look like:
    # <a href="/?Fun=Cause_1589&spc=Canine&dxkw=&sxkw=&signs=1-A00"&" class=news>...</a>
    # We'll keep those with class "news" and href containing "Fun=Cause_"
    anchors = soup.select("a.news")

    diags: List[str] = []
    seen = set()

    for a in anchors:
        href = a.get("href", "") or ""
        if "Fun=Cause_" not in href:
            continue
        text = a.get_text(" ", strip=True)
        if not text:
            continue
        if text in seen:
            continue
        seen.add(text)
        diags.append(text)

    return diags


def main() -> None:
    signs = read_signs_txt(INPUT_TXT)
    if not signs:
        raise SystemExit(f"No valid rows found in {INPUT_TXT}")

    session = requests.Session()
    session.headers.update({
        "User-Agent": "Mozilla/5.0 (X11; Linux x86_64) CornellConsultantScraper/1.0 (+non-commercial research)",
        "Accept": "text/html,application/xhtml+xml,application/xml;q=0.9,*/*;q=0.8",
        "Accept-Language": "en-US,en;q=0.9",
        "Connection": "keep-alive",
    })

    out: List[dict] = []
    errors: List[Tuple[str, str]] = []

    for i, row in enumerate(signs, start=1):
        url = URL_TMPL.format(code=row.code)
        try:
            html = fetch_html(session, url)
            diags = extract_diagnoses(html)
            entry = {
                "Proceso": row.proceso,
                "especialidades": infer_system(row.code),
                "Diagnósticos diferenciales": diags,
                "meta": {
                    "sign_code": row.code,
                    "url": url,
                }
            }
            out.append(entry)
        except Exception as e:
            errors.append((row.code, str(e)))

        # polite delay
        time.sleep(SLEEP_SECONDS)

        # optional progress
        if i % 25 == 0:
            print(f"Progress: {i}/{len(signs)}")

    payload = {
        "source": "consultant.vet.cornell.edu",
        "species": "Canine",
        "generated_from": INPUT_TXT,
        "count": len(out),
        "items": out,
        "errors": [{"code": c, "error": msg} for c, msg in errors],
    }

    with open(OUTPUT_JSON, "w", encoding="utf-8") as f:
        json.dump(payload, f, ensure_ascii=False, indent=2)

    print(f"Saved: {OUTPUT_JSON}  (items={len(out)}, errors={len(errors)})")


if __name__ == "__main__":
    main()
Consejo práctico: si quieres que el JSON final sea solo una lista (sin meta/count/errors), basta con guardar out directamente en OUTPUT_JSON.
