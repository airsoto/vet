Desarrollado por: Ángel Soto

🏠 volver a página de inicio

Visor lunar 3D con rotación, zoom y soporte Apple Quick Look. Para web interactiva, usa GLB; para Apple, mantén también el USDZ.

🖱️ Arrastra para rotar
🔍 Rueda o pellizco para zoom
🌕 Auto-rotación activa
Abrir USDZ en Apple Descargar USDZ

Importante

El archivo que se muestra en el visor web debe ser preferiblemente: Moon_NASA_LRO_23k_Flat.glb

El archivo Apple/AR puede seguir siendo: Moon_NASA_LRO_23k_Flat.usdz

Si solo tienes USDZ, en muchos navegadores no se mostrará correctamente dentro del visor.
