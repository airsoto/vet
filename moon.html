Cómo se usa

  • Arrastra sobre la Luna para cambiar la orientación visual.
  • Usa la rueda del ratón o pellizco en móvil para acercar o alejar.
  • Pulsa Abrir modelo USDZ para abrir el archivo alojado en tu carpeta imagenes.

Consejo

Esta página ya queda bonita y funcional en GitHub Pages incluso aunque el modelo no se renderice directamente dentro del navegador como un visor 3D universal.

Más adelante, si quieres, te la convierto a una versión con visor 3D real usando un archivo adicional GLB.
