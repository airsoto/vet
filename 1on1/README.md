# Clutch Duel

Versión web original inspirada en los juegos retro de baloncesto uno contra uno. No usa sprites, música ni sonidos extraídos del juego comercial original.

## Modos

- Duelo 1 vs 1 con rival controlado por IA.
- Concurso de triples con puntuación por tiros lejanos.
- Concurso de mates con bonificación por acercarse al aro corriendo.

## Controles

- iPhone/táctil: joystick izquierdo, botones Tirar, Correr y Robar.
- Teclado: WASD o flechas para moverse, Espacio/Z para tirar, Shift para correr y X para robar/bloquear.

## Publicar en GitHub Pages

1. Sube todos los archivos de esta carpeta a un repositorio.
2. En GitHub, abre Settings > Pages.
3. Selecciona la rama principal y la carpeta raíz.
4. Guarda y abre la URL que GitHub Pages genere.
